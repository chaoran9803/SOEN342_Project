## Requirements

- JDK 11 or later

## Compile and run

Run these commands

```
javac -d out -sourcepath src src/Main.java
java -cp out Main
```

## Quick start

1. Choose **1** and enter `data/availabilities.csv` to load the professionals and their slots.
2. Choose **2** and enter `data/appointments.csv` to load the booked appointments. This must be done after step 1.
3. You can now use the other options.
